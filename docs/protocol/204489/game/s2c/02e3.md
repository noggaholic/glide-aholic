# Remove effect

Build **204489** | `game` | `s2c` | `0x02E3`

Remove a previously published effect instance.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `subject` | `varuint32` |  | Actor receiving the effect. |
| 2 | `secondary_actor` | `varuint32` |  | Second actor field. Condition and personal-effect writers repeat the subject; TauntState uses the caster instead. |
| 3 | `instance` | `varuint32` |  | Effect instance ID. Conditions use a reserved namespace; other effects use separate instance IDs. |

## Notes

- Maintained effects can use duration zero. For a taunt, the secondary actor is the caster and can differ from the subject.
