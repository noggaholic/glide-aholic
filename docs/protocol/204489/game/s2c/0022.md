# Movement relay 0x0022

Build **204489** | `game` | `s2c` | `0x0022`

Encode a character command used by movement relays and stationary skill orders.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `agent` | `u16` | min_value=1 | Recipient-visible body/agent identifier written by the relay. |
| 2 | `sequence` | `varuint32` |  | Server movement sequence supplied to the relay. |
| 3 | `state` | `u8` |  | Command state byte. |
| 4 | `identity` | `varuint32` |  | Order identity, separate from the scheduling sequence. |
| 5 | `input` | `bytes_u8` |  | Command-specific input. |
| 6 | `duration_ms` | `u16` |  | Skill duration or forwarded movement duration. |

## Notes

- The body/agent identifier and sequence are replaced when forwarding this message.
- Timed orders use state 16 and a 13-byte input: tag 120, zero, U32 skill, U8 slot, zero, U32 target and one environment byte. The environment byte is zero on 167409; on 204489 it is 1 for land or 3 for water. Instant orders use state 48 and an 11-byte input: tag 122, zero, U32 target, U32 skill and U8 slot, followed by duration 1.
- Skill input uses tag 120. A final phase is followed by the separate S84 end signal.
