# Create effect

Build **49284** | `game` | `s2c` | `0x01F1`

Publish an effect instance for the subject actor.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `subject` | `varuint32` |  | Actor receiving the effect. |
| 2 | `secondary_actor` | `varuint32` |  | Second actor field. Condition and personal-effect writers repeat the subject; TauntState uses the caster instead. |
| 3 | `definition` | `varuint32` |  | Effect definition ID. |
| 4 | `instance` | `varuint32` |  | Effect instance ID. Conditions use a reserved namespace; other effects use separate instance IDs. |
| 5 | `duration_ms` | `varuint32` | min_value=0 | Duration in milliseconds. Zero is allowed for maintained effects; conditions use 1..3600000. |
| 6 | `modifier_scalar` | `u8` | max_value=255 | Effect modifier. Carries the level for conditions, taunts and maintained effects. Meaning for other effects is unknown. |
| 7 | `flags` | `u8` | fixed_value=1 | One. |

## Notes

- Maintained effects can use duration zero. For a taunt, the secondary actor is the caster and can differ from the subject.
