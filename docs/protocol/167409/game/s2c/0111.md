# Attach equipment item

Build **167409** | `game` | `s2c` | `0x0111`

Attach a restored item instance to an equipment slot.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `agent` | `varuint32` |  | Actor whose equipment changes. |
| 2 | `instance` | `varuint32` |  | Item instance in this actor view. |
| 3 | `slot` | `u8` |  | Equipment slot. |

## Notes

- Inventory changes are sent to the owner and observers after saving succeeds. Failed saving returns a service notice and leaves the inventory unchanged.

## Referenced by

- [game c2s 00a0](../../../167409/game/c2s/00a0.md) (reply): Sent after a valid inventory change has been saved. Failed or unavailable actions can return a service notice instead.
