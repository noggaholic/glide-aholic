# Legend selection

Build **167409** | `game` | `s2c` | `0x01DB`

Publish the selected base legend pair and remaining swap delay.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `agent` | `varuint32` |  | Revenant actor. |
| 2 | `remaining_ms` | `varuint32` |  | Remaining legend swap delay. |
| 3 | `water` | `u8` | allowed_values=[0, 1] | One selects the aquatic pair; zero selects the land pair. |
| 4 | `legends` | `array_u8` | 2 | Selected pair of base legend IDs. |
| 1 | `legends.legend` | `u8` |  | Base legend identifier. |

## Notes

- Build 49284 sends a single pair followed by the active profession state. Builds 167409/204489 include a land/water selector and limit remaining_ms to 10000.
