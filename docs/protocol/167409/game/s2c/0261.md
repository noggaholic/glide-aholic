# Skill recharge

Build **167409** | `game` | `s2c` | `0x0261`

Set the remaining and total duration of a skill recharge.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `agent` | `varuint32` |  | Character actor whose skill timer changes. |
| 2 | `skill` | `varuint32` |  | Skill definition ID. |
| 3 | `timer_kind` | `u8` | fixed_value=0 | Skill recharge kind. |
| 4 | `remaining_ms` | `varuint32` |  | Remaining duration in milliseconds. |
| 5 | `total_ms` | `varuint32` |  | Total duration in milliseconds. |
| 6 | `field_06` | `u16` | fixed_value=0 | Zero. |

## Notes

- Remaining duration must not exceed total duration.
- Uses local actor 57344. An alternate facet skill also updates its base skill with the same deadline: alternate 27228 updates base 27220. Remaining duration must not exceed total duration.
