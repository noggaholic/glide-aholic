## Notes

- The body/agent identifier and sequence are replaced when forwarding this message.
- An 18-byte request body beginning with action discriminator 12, 2 produces a 22-byte action body followed by a separate 0x0047 message. Other bodies are ignored.
- Skill input uses tag 120. A final phase is followed by the separate S84 end signal.
