## Notes

- Decoding the wire layout does not by itself authorize character creation. Session state and submission validation are separate checks.
- Requires a matching loadout, valid palette IDs, a nonempty name of at most 19 UTF-16 units and a valid character summary.

## Referenced by

- [game s2c 01d4](../../../14422/game/s2c/01d4.md) (reply): Sent after the creation session accepts and saves the submission. Decoding the request alone does not perform that transaction.
