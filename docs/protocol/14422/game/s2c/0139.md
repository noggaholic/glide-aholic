# Create effect

Build **14422** | `game` | `s2c` | `0x0139`

Publish an effect instance for the subject actor.

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `subject` | `varuint32` |  | Actor receiving the effect. |
| 2 | `secondary_actor` | `varuint32` |  | The reviewed condition and positive-effect writers repeat the subject. |
| 3 | `definition` | `varuint32` |  | Effect definition ID. |
| 4 | `instance` | `varuint32` |  | Effect instance ID. Conditions use a reserved namespace; other effects use separate instance IDs. |
| 5 | `duration_ms` | `varuint32` | min_value=0 | Duration in milliseconds. Conditions use 1..3600000; other effects can have different limits. |
| 6 | `modifier_scalar` | `u8` | max_value=80 | Modifier byte supplied as level by the reviewed beta effect writers. Native interpretation is not independently confirmed. |
| 7 | `flags` | `u8` | fixed_value=1 | One. |

## Notes

- Positive effects and conditions share this layout. Their duration limits differ.
