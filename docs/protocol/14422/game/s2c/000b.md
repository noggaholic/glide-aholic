## Notes

- Initial skill input begins with U8 tag 35 and U8 zero, then U32 skill, U8 slot, U8 stage index, U32 target and U8 environment (1 land, 3 water). Later-stage input uses tag 35, U8 4, stage index and U8 3. A final stage appends the separate skill-end message. Moving stages use their movement envelope instead.
- Used for initial and subsequent skill stages, stationary or moving, on land or underwater. A final stage is followed by a skill-end signal.
