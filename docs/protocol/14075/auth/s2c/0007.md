# Character roster entry

Build **14075** | `auth` | `s2c` | `0x0007`

Describes one character in the local roster.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `request` | `varuint32` |  | Retained value. |
| 2 | `character_guid` | `raw` | 16 | Roster character GUID. |
| 3 | `field_03` | `varuint32` |  | Zero. |
| 4 | `character_name` | `utf16z` | 19 | Roster character name. |
| 5 | `summary` | `bytes_u16` | 153 | CharacterSummary emits 153 bytes. Internal summary fields are not expanded here. |

## Notes

- Requires a nonzero request ID, a nonempty character name and a valid character summary.
