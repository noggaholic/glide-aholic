# Movement relay 0x0027

Build **14075** | `game` | `s2c` | `0x0027`

Connection: World.

## Fields

| # | Field | Wire type | Constraints | Meaning |
|---:|---|---|---|---|
| 1 | `agent` | `u16` | min_value=1 | Recipient-visible body/agent identifier written by the relay. |
| 2 | `sequence` | `varuint32` |  | Server movement sequence supplied to the relay. |
| 3 | `state` | `u8` |  | Unknown. |
| 4 | `flags` | `varuint32` |  | Unknown. |
| 5 | `input` | `bytes_u8` | 80 | Opaque motion input, at most eighty bytes. |

## Notes

- The body/agent identifier and sequence are replaced when forwarding this message.
- Missile movement input is 31 bytes on 14075 and 40 bytes on 14422/14505/14812. Hit input uses tag 1 followed by U32 identity and U32 target. Surface input on 14422/14505 uses tag 2 followed by U32 identity. These visual notifications do not carry a health change.
- Used for initial and subsequent skill stages, stationary or moving, on land or underwater. A final stage is followed by a skill-end signal.
